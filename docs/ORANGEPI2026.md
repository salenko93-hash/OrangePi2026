# OrangePi2026

Створено 2026-11-03 на основі наданого LyceumTV 3.7.5 для Orange Pi PC.
Цільовий репозиторій: https://github.com/salenko93-hash/OrangePi2026.

Цільова платформа й вимоги ОС успадковані з вихідного проєкту: Orange Pi PC,
Allwinner H3, armhf, 1 ГБ RAM; systemd, Cage та WebKitGTK 6.0.
Функції розкладу, укриття, тривог, оголошень, медіа, мобільного перегляду,
адміністрації, backup та транзакційних оновлень збережені.

Сервер, CLI оновлення й Windows-інсталятор довіряють релізам OrangePi2026.
Релізи попереднього репозиторію OrangePi не приймаються. Версія застосунку
залишена 3.7.5, оскільки створення окремого репозиторію не є новим релізом.

До коду включено початкові розклади `data/default` та їхні XLSX-джерела.
Робочі конфігурації, медіа пристрою, ключі, кеші й налаштування IDE не перенесені.
Документи в `reports` успадковані як історія вихідного проєкту; вони не засвідчують
перевірку нового репозиторію чи фізичної плати.

Перевірка коду: `python -B VERIFY_PROJECT.py`.
Збирання ZIP та SHA-256: `python -B tools/build_release.py`.
CI виконує перевірки на Windows і Ubuntu, без встановлення на плату.
Публікація вихідного коду не створює GitHub Release автоматично.
HDMI, звук, продуктивність і холодний запуск потребують перевірки на Orange Pi PC.
